# Angular 

## Documentation

[https://https://angular.dev/overview](https://https://angular.dev/overview)

```
npm install -g @angular/cli

ng new my-app

cd my-app
ng serve --open
```

## Adoptions

UI for the time being MaterialUI

```
ng add @angular/material
```
