# UX [^](./articles/)

## 1. UX Basics

### What is UX?

UX describes the overall experience a user has while interacting with a system
or product.

### What is the difference between UX and Usability?

UX is about a delightful experience while Usability assures that user
accomplishes their goal.

### How does UX pay off?

UX pays off in business value (e.g., increased revenue, customer loyalty, brand
value) and in human value (e.g., enjoyment, emotional satisfaction)

### What are value streams?

Value streams …

- consist of a set of actions that add value to the customer
- involve the entire lifecycle of a product or service
- the next big thing at your company

## 2. User Research

### How does the briefing influence the user research?

UX Briefing scopes the project and the research Helps to identify the user roles
and the work flows

### Why do we conduct generative research?

- Understand the social and physical environment.
- Understand user’s behaviors, preference, and pain points.
- Understand user’s feelings.
- Collect data that guide user requirements and design decisions.
- Avoid focusing on the wrong topics during the design
- Minimize extra spendings for late changes

### Means

- Personas - Specify our target user, representing a user group Fictional, yet
  realistic, description of a typical or target user of the product. Contains
  selection criteria for the recruitment of user representatives

## Journey map

### Approaches

- Assumption-first: educate stakeholders, understand knowledge gap; it needs to
  be validated with representatives of the user role / persona
- Research-first: evidence-based; requires inputs from user representatives and
  avoids team bias.

### How does a persona influence a journey map?

- Identifies a relevant user role
- Introduces first characteristics about the persona
- A persona helps to recruit representatives of the user role

### Why do we create journey maps?

- Understanding the current user’s experience
- Identify pain points in the context of current user activities
- Highlight opportunities in the context of current user activities
- Aligning stakeholders to share the current and potentially improved user
  experience
- Prioritizing design activities by focusing on most critical user activities
  first
- Emphasizing a user-centric approach
- Have baseline for improvements
