Albums

iMGSRC.RU album → image gallery

Paste an album, photo, or tape URL. The page starts at the album's initial view, continues to the “all images on one page” view, collects every full-size image and renders a list you can export as a standalone HTML file. When the same photo is offered in several formats, it is listed once and the WEBP version is preferred (falling back to the other formats when no WEBP file exists).

Connection settings

iMGSRC.RU does not send CORS headers, so the browser cannot fetch it directly. The default reader relays the request (it sees the album URL, including any ?pwd= token). For a local-only relay, run node cors-proxy.mjs and open http://localhost:8787.

Album

Select an album to see its previews.

How it works: the page loads the album’s initial view (deriving it from a tape-… URL when needed), then continues to the tape-… “all images on one page” view. It reads the full-size image URLs from <source> and <img> elements, groups the variants of the same photo into a single entry, prefers the WEBP file and paginates through the album. Adult-content warnings and “foreword” pages (?preword=show) are skipped automatically. The HTML button next to an album downloads a standalone gallery file. Images stay on the iMGSRC CDN.
